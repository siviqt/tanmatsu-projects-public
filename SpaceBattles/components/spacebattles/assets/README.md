# Embedded artwork

`loading.jpg` and `logoff.jpg` are the accepted 800×480 lifecycle backgrounds.
`menu.jpg` is the text-free fleet/planet plate used by the GUI v3 entry screens,
match menus and deployment. All three are embedded build inputs; normal firmware
builds require no conversion tools.

`tools/prepare-cyberdeck-assets.py` reproduces `menu.jpg` from the preserved
`assets/cyberdeck-v1/menu-background-master.png` using Pillow (quality 88,
4:4:4, baseline JPEG). Regeneration was byte-identical during GUI v3 validation.
The retained `render/title.h` contains the 600×60, 4-bit alpha title mask; its
original raster master was absent from the supplied checkout. The mask itself
is a complete build input and is no longer regenerated by a broken script.

The hardware JPEG driver uses the existing RGB565 artwork buffer. A native
framebuffer cache includes the illustration and radar lattice; menu navigation
and deployment restore it without decoding or allocating per input. If cache
allocation or decode fails, opaque solid backgrounds remain available. Reading
panels and tactical cells are opaque. Private handovers clear the full frame.
No additional full-screen buffer was introduced for GUI v3.

Frames, function-key badges, wireframe ships and focus indicators are drawn by
PAX. The former physical-symbol key atlas and unused emblem header are omitted;
neither is compiled.

Font sources, bitmap data and SIL Open Font License notices remain in `fonts/`
and `../render/font_assets.c`. The project README lists the retained rendering
and application regression tests.
